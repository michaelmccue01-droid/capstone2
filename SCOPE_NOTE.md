# Project scope note

The approved proposal asked which U.S. housing markets might be undervalued. The available capstone dataset contains only state-level home-value histories. That is enough for time-series forecasting, but it does not include the rental, affordability, supply, migration, or financing variables needed to estimate investment value.

The final project therefore answers a narrower question: how accurately can recent Florida ZHVI observations predict the following month? The report and presentation explain this change directly so the conclusions do not overstate what the data supports.
