# Data notes

`zhvi.csv` contains monthly Zillow Home Value Index values for 50 states and the District of Columbia from January 2000 through January 2026.

- Rows: 313 monthly observations
- Value columns: 51 states/districts
- Modeling target: Florida
- Missing Florida values: 0
- Underlying publisher: Zillow Research
- Original download location recorded by the earlier notebook: Kaggle (exact page not preserved)

ZHVI measures a region's typical home value and market changes. It should not be described as an individual property's sale price.

Source documentation: https://www.zillow.com/research/data/
